## Authority and versioning

This is the authoritative current Kiduna Sigil Lexicon. Every released change receives a new version number and Eastern date/time. The current file is replaced only by a newer release; the versioned file in `releases/` is immutable.

The Lexicon preserves every sigil in the source library, including legacy and provisional assets. **Category** states where each sigil belongs under the current Taxonomy Canon. When a library name no longer matches current Canon, that difference is stated directly instead of silently rewriting the asset.

The public name **Complementarity** supersedes the earlier display name **The Sun and The Moon**. Its stable source slug and filename remain unchanged so existing implementations do not break.
